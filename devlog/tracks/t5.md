## 2026-11-15 ③ 판넬 말투 — 어제는 금박, 오늘은 무너진 청록 돌

- 무엇을: `src/ext/t5/theme.js`. 시대에 따라 바뀌는 색 변수(`--pn-*`)와 판넬 틀(귀퉁이 장식: 어제 = 금 덩굴, 오늘 = 금 간 돌덩이), 제목 아래 장식 띠, 단추(고르면 단검 커서가 까딱). T1 메뉴·지도·요약, T4 고르기·쉼터·저주 고르기·가방·서고, 끝 화면, 시작·멈춤 카드가 모두 이 말투를 쓴다.
- 카드: 희귀도 색 테 + 가운데 메달 받침 위 아이콘 + 희귀도 보석(흔함 1·드묾 2·전설 3), 저주 메달은 점선 테.
- 지도: 지도판 위 메달 칸, 지나온 칸은 빛바래고 체크, 지금 칸 위 붉은 핀, 지나온 길은 시대 강조색 실선.
- HUD: 하트 그림(잃으면 점선 빈 홈), 모래시계 + 유리관 계량기, 금화·탄 명판, 희귀도 테 유물 타일, 시대 이름 옆 문장(어제 해는 천천히 돎), 성채지기·문지기 체력은 보석 점, 두 번 실패한 tip 앞은 등불, E 안내는 판넬. 밝은 금빛 바닥에서도 읽히게 위쪽 두 귀퉁이를 살짝 어둡게.
- 상점 받침대·모닥불·값표(3D)도 이모지 텍스처 대신 그린 아이콘을 캔버스에 그린다.
- 공용 파일은 `src/ext/index.js` 한 줄(`core:`)만. index.html·main.js의 HUD는 T5 CSS가 덮는다.
- 전후: `cmp-01`~`cmp-13`(HUD 두 시대, 런 HUD, 고르기, 지도, 메뉴, 요약, 가방, 쉼터, 상점, 서고, 휴대폰 지도·고르기).
- 읽을 문장:
  - 판넬은 어제 화면에선 금박, 오늘 화면에선 금 간 청록 돌로 바뀌어요.
  - 유물 카드는 가운데 메달 위에 그림이 올라가고, 희귀할수록 보석이 늘어요.
  - 지도에는 지금 있는 칸 위에 붉은 핀이 꽂히고, 지나온 길은 빛나는 선으로 남아요.
  - 상점 받침대 위에 떠 있는 그림도 이제 같은 그림체예요.

## 2026-11-15 ④ 직접 플레이 — 처음 보는 사람처럼 한 판

- 어떻게: `py -I tools\play_server.py 8155`(화면 없는 크롬 + 진짜 키 입력), 저장이 빈 새 브라우저로 시작.
- 한 것(약 25분): 시작 카드 클릭 → 튜토리얼 1방(Shift로 다리 건너기) → 2방(오늘의 무너진 벽으로) → 3방(레버 — 덜 다가가 E가 안 먹고, 오늘 구덩이 자리에서 Shift를 눌러 떨어짐, 하트 4) → 4방(멈춘 경비 등 뒤에서 어제로 넘어가며 찌르기). 남은 튜토리얼 9방은 `release_check` 봇에 맡기고 '튜토리얼 끝'만 켰다.
  런 1판: 메뉴 → 새 런 → 계단참 → 지도 → 「봉인 뒤의 마법사」(T3 거울 퍼즐, 1층 첫 줄) — 어제에서 경비에게 두 번 들키고, 거울이 손 닿는 거리(2.45m) 밖이라 E가 안 먹어 헤맴, 하트 1로 깸 → 보물 제단에서 E → 고르기 창(방향키·Enter로 「고요한 수확」) → 유물 타일 눌러 툴팁, Tab 목록 → 지도 → 「0.7초의 다리」에서 다리 옆 구덩이에 떨어져 쓰러짐 → 런 요약(4분 1초) → 기억의 서고 → 새 런 → 저주 고르기(저주 없이) → 새로고침 → 메뉴 「이어하기」 → Esc 일시정지 → 아무 키로 계속. 쉼터(모닥불 E → 쉬기 → 하트 3→5)와 상점(받침대 앞 설명 카드 → E로 사기)은 그 방으로 바로 가서 걷고 눌렀다.
- 찾아서 고친 것 (화면):
  1. 오른쪽 위를 어둡게 깐 막이 시대 이름 위를 덮어 흐려짐 → 막을 HUD 뒤로(z-index).
  2. 고르기 창 뒤로 방 이름·토스트가 비쳐 제목과 겹침 → T4 창이 떠 있으면 그 뒤 HUD 글을 숨김.
  3. 잃은 하트가 어두운 모서리에서 아예 안 보임 → 점선 빈 홈 그림으로.
  4. 시작·멈춤 카드, 메뉴 작은 글이 낱자에서 끊김("아니\n요") → 낱말 단위 줄바꿈.
  5. '저주 없이' 카드 이름이 흐린 회색 → 밝게.
  6. 휴대폰 세로: 단검 커서가 판넬 밖으로 삐져나옴, 방 이름·토스트가 오른쪽 유물 칸과 겹침 → 커서는 단추 안쪽, 방 이름·토스트는 유물 칸을 비켜 왼쪽으로.
  7. 런 덮개(지도·요약) 뒤로 금화·유물 줄이 비침 → 덮개가 뜨면 숨김.
  8. 시작 카드 두 제목이 함께 보이는 실수(내가 넣은 CSS가 index.html의 숨김을 이김) → 보이는 쪽만 보이게.
  9. T3 씨앗·열쇠 HUD가 매 프레임 글을 갈아 끼움 → 값이 바뀔 때만, 그린 아이콘으로.
