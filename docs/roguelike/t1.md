# T1 런 구조·절차 생성 (11/13, 브랜치 rl-t1)

코드: `src/ext/t1-run.js`(슬롯·훅·런 흐름·`EXT.run`) + `src/ext/t1/`
(`rng.js` 시드 난수 · `gen.js` 조각 조립 · `chunks.js` 조각 창고 · `map.js` 층 지도 · `ui.js` 화면·모래 계량기·키 · `temp-rooms.js` 계단참·임시 보물/상점/쉼터 · `en.js` 영어).
시험 도구: `tools/t1_play.py`(직접 플레이 도우미), `tools/t1_lazy_bots.js`(게으른 봇). 공용 파일 수정 없음(`core:` 커밋 없음).

## 1. 흐름

| 상황 | 무엇이 뜨나 |
|---|---|
| 처음 하는 사람 (`yk-tut` 없음) | 지금의 13개 방 = 튜토리얼. 끝 화면에 **"튜토리얼 끝! … 런 시작"** 단추가 붙고 `yk-tut = 1` 저장 |
| 튜토리얼을 깬 뒤 접속 | "클릭해서 시작" → 시작 메뉴: **이어하기**(저장된 런이 있으면, n층·방·♥·⌛) / **새 런** / **튜토리얼 다시 하기**. 이어할 런이 있으면 "새 런"은 두 번 눌러야 함 |
| `?seed=123` | 바로 그 시드의 런 (같은 시드로 저장된 런이 있으면 이어하기, `&fresh=1`이면 새로) |
| `?tutorial` | 튜토리얼부터 |
| `?room=<id>` | 지금처럼 그 방만 (런과 상관없음) |

런 = **층 3개 × 지도 5줄** + 마지막 성채지기.
층마다 계단참(작은 안전한 방) → 출구를 밟으면 **층 지도**(`#ext`, 세상 멈춤) → 이어진 칸 중 하나를 골라 들어감 → 방을 나오면 다시 지도 → … → 맨 위 줄 **문지기**(1·2층) / **성채지기**(3층).

지도 줄: 0줄 = 전투·퍼즐 둘, 1줄 = 셋(전투·퍼즐·보물·정예(2층부터)), 2줄 = 둘~셋(전투·퍼즐·정예·상점·보물), 3줄 = 쉼터 + 상점/보물, 4줄 = 문지기/성채지기.
칸마다 되도록 두 갈래(엇갈리는 선은 안 만듦) — 40시드 평균 1.61갈래, 계단참에서는 늘 두 갈래.
←/→(A/D) 고르기, Enter/Space/E 들어가기, 숫자 1~9, 마우스·터치 모두.

## 2. 방 만들기 (`gen.js`, `chunks.js`)

- 조각 창고 = 튜토리얼 12방(성채지기 방 제외, 가중치 낮게) + rooms.js에만 있던 함정 방 3(멈춘 문·가시 회랑·썩은 상자) + **T1 일반 조각 9개** + `EXT.chunks`(T2·T3, 가중치 1.6).
- 칸 종류 → 원하는 꼬리표: 전투 `combat`/`elite`, 퍼즐 `puzzle`, 정예·문지기는 단계 +1이고 `elite` 꼬리표를 3배로.
- 층별 단계: 1층 tier 1(60%)·2(40%), 2층 2·3, 3층 3·4. 조각 단계가 원하는 단계와 1 차이면 0.45배, 2 차이면 0.08배. 이번 런에서 이미 쓴 조각은 0.12배.
- **이어 붙이기**: 1층 30%, 2층 55%, 3층 75%, 정예 +35%, 문지기 100%. A의 출구 → 동쪽(E) 또는 북쪽(N) 벽에 문 하나 → B의 시작.
  조건: 출구~벽까지 곧게 두 시대 모두 평범한 바닥, 그 벽 줄이 모두 `#`, 그 길에 자기 시작 칸이 없고 문이 시작보다 출구에 가까움(뒤집힌 조각이 막다른 곁길이 되지 않게), 발판·시간 문(`G`/`p`)이나 레버(`L`/`D`)가 두 조각에 다 있으면 안 이음(방에 하나뿐인 장치), 크기 34×18 / 30×22 이하.
- 풀이가 안 깨지는 변형만: **좌우 뒤집기**(경비 방향·조각·박자 함수까지), 경비 쉬는 시간 ±20%, 함정 박자를 통째로 미루기(서로의 엇박 그대로), 단계가 높으면 조각의 `extra`(그 단계 이상에서 더하는 적) 추가.
- 만든 방은 `(칸, 시대)` 그래프로 대강 검사(시작→출구, 적 첫 자리). 실패하면 첫 조각만. 다른 트랙 장치 글자(`EXT.chars`)가 든 방은 그 트랙의 풀이 확인을 믿는다.
- 시드: `makeRng(seed, 'room', 층, 줄, 칸)` → 같은 시드·같은 길이면 같은 방. 지금 방의 조립법(`recipe`)을 저장해 이어하기에서 그대로 다시 만든다.

## 4. 죽음·이어하기·런 사이

- 하트는 방을 지나도 그대로(튜토리얼과 같음), 다 잃으면 `death` 훅 → **런 끝 요약**(내려간 층·지난 방·쓰러뜨린 적·맞은 횟수·어제에서 쓴 모래·걸린 시간·기억 +n·시드) → 새 런 / 같은 시드로 다시 / (T4 있으면) 기억의 서고 / 튜토리얼.
- 성채지기 방을 나오면 승리 요약(기억 +10).
- **저장**(`yk-run`): 방에 들어갈 때·지도를 열 때. 창을 닫았다 열면 메뉴의 "이어하기" → 그 방 처음부터(들어올 때의 하트), 지도에서 닫았으면 그 층 계단참 → 출구 → 고르던 지도.
- **런 사이 재화 = 기억**(`yk-meta`, T4 meta.js와 같은 열쇠·필드 `memory·runs·wins·best·total·unlocked` + T1의 `bestFloor`). T4가 있으면 계산·저장은 `EXT.t4.endRun`(지난 방 + 층×3 + 이기면 10 + 금화÷4), 없으면 T1이 방 1 · 정예 2 · 문지기 3 · 승리 10. 서로의 필드를 지우지 않는다.
- 런 방의 별 기록(`yk-best`)은 출구에서 지운다(튜토리얼 기록만 남게).

## 5. T4에 내주는 것 — `EXT.run`

```js
EXT.run.state            // 저장되는 런 상태 { seed, floor, pos, visited, phase, hearts, sand, recipe, used, stats, t4 … } (pending이면 아직 안 시작)
EXT.run.active()         // 런 중인지
EXT.run.floor            // 지금 층 (숫자 — T4 rooms.js가 값으로 씀)
EXT.run.seed()           // 시드 문자열
EXT.run.sand() / sandMax() / addSand(n, why) / setSand(v)
EXT.run.node()           // 지금 방 { kind:'node'|'landing', floor, row, col, type }
EXT.run.map()            // 이 층 지도
EXT.run.rng(...tags)     // 이 런 시드로 만든 난수 (T4가 같은 시드에 같은 물건을 내고 싶을 때)
EXT.run.heal(n)          // 하트 회복(최대 EXT.stats.maxHearts)
EXT.run.registerRoomType(type, fn | { make(opts), decorate(room, opts) }, meta?)
//   fn(ctx) → 방 데이터. ctx = { floor, row, col, type, seed, rng, K, state, temp(T1 임시 방 함수) }
//   T4 꼴: make({ tier, label, floor, rng, seed }) → 방 데이터 (보물·상점·쉼터가 T4 것으로 바뀜)
//   meta = { icon, name, desc, color, rows:[1,2], weight } 이면 새 지도 칸 종류
EXT.run.meta.get() / add(n) / spend(n)   // 기억
EXT.run.start(seed?)     // 새 런 바로 시작
EXT.run.save()
EXT.stats.sandMax / sandDrain / sandMul  // T4 유물이 바꾸는 모래 값
```
훅(EXT.on): `runStart(state)`, `runResume(state)`, `roomEnter(room, node, state)`, `roomPick(node, state)`, `mapOpen(choices, state)`, `roomClear(room, node, state)`, `floorStart(floor, state)`, `sand(got, why, state)`, `sandOut(state)`, `runEnd(result, state)`, `runSummary(slotEl, { result, state, meta, gain })`.

**T4가 있으면 T1이 부르는 것**(T4 문서 5장 그대로): 런 시작 `EXT.t4.startRun()`, 저장 때 `snapshot()` → 이어하기 때 `restore()`, 정예·문지기를 나올 때 `openPick({ count:3, tier: 층, title })`(고르는 동안 세상 멈춤, 고른 뒤 지도/다음 층), 런 끝 `endRun({ won, floors, rooms })`, 요약 화면 "기억의 서고" → `openMeta()` 닫으면 새 런.
11/13 T1+T4를 겹친 임시 사본에서 확인: T4 보물·상점·쉼터 방 사용, 정예 뒤 고르기 창 → 지도, 새로 고침 뒤 유물 복원, 죽음 → 기억 +4(T4 계산) → 서고 → 새 런. 콘솔 오류 0.

## 7. 2차 (11/15) — 난이도 곡선·안내 문구·층 테마·문지기 자리·성채지기 연결

### 난이도 곡선 (`FLOORS[f].tierAt`, 지도 줄마다)

| 층 | 0줄 | 1줄 | 2줄 | 문지기 | 모래 최대 | 이어 붙일 확률 |
|---|---|---|---|---|---|---|
| 1 | 2 | 2 | 2.4 | 3 | 16 | 40% |
| 2 | 2.5 | 3 | 3.2 | 4 | 15 | 65% |
| 3 | 3 | 3.5 | 4 | 4 (+ 성채지기) | 14 | 85% |

- 소수 = 그 비율로 한 단계 위. 정예는 +1. 단계 가중치는 비대칭(하나 어려운 건 0.4, 하나 쉬운 건 0.15) — 쉬운 조각이 수가 많아 평균이 끌려 내려갔다.
- 2층부터 전투 칸은 적이 많은 조각을 조금 더(적 하나당 +12% × (층 − 1)). 층 테마에 맞는 적·장치는 더 자주(`theme.js`의 `foe`·`tag`).
- **"생각 없는" 조각은 혼자 안 씀**: `think: 0`이거나 T1 표(`tut-bridge`, `tut-bars`, `t3-crumble1`)이거나, 1층 0·1줄의 tier 1 조각은 다른 조각과 이어 붙일 때만. 짝이 없으면 다른 조각을 뽑는다.
