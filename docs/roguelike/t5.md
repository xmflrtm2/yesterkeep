# T5 UI 아트 — 그린 아이콘 한 벌과 시대 판넬 (11/15)

개발자님 말(11/15): "UI에 쓰이는 이미지가 지금 기본 이모지일 텐데, UI들 게임스럽게 개선하고 좀 어제의 성채 느낌 나는 그림들로 그려서 넣게끔."
그래서 화면에 나가던 OS 이모지·유니코드 기호를 **코드로 그린 SVG 아이콘 83개**로 바꾸고, 메뉴·지도·고르기 창·상점·쉼터·요약·끝 화면·HUD를 **한 가지 판넬 말투**로 다시 꾸몄다. 아무것도 내려받지 않았다(외부 이미지 생성·새 글꼴 없음).

## 2. 아이콘 쓰는 법

```js
import { icon } from '../t5/icons.js';        // 트랙 파일에서 (또는 EXT.icon — import 없이)
el.innerHTML = icon('coin') + ' 12';           // <svg class="yi yi-coin"><use href="#yk5-i-coin"/></svg>
icon(it.id, { fb: it.icon })                    // 유물: 등록 안 된 id면 원래 이모지(fb)를 그대로 → 새 유물을 넣어도 안 깨짐
icon('🪙')                                      // 이모지가 그대로 와도 그 아이콘으로 (GLYPH 표)
iconUrl('tip')                                  // CSS background: url("data:image/svg+xml…")
iconImage('flame', 256).then(img => ctx.drawImage(img, …))   // three.js 캔버스 텍스처용 (비동기)
```

- 크기는 글자 크기를 따른다(`.yi { width: 1em; height: 1em }`). HUD는 16~28px, 카드 메달은 52px.
- **새 아이콘 넣기**(다른 트랙): `EXT.icons.add('t2-foo', '<path …/>')` 또는 `icons.js`의 `ICONS` 표에 한 줄. 24×24 격자, 아래 도우미로 그리면 한 벌처럼 보인다.
  - `P(d, 채움)`·`C(cx,cy,r,채움)`·`R(x,y,w,h,rx,채움)`·`E(…)` — 채움은 `g('gold')` 같은 그러데이션. 윤곽은 자동(고동색 1.8, 채움 아래)
  - `L(d, 색, 굵기)` 윤곽 있는 선(밧줄·호), `D(d, 색, 굵기)` 윤곽 없는 무늬 선, `HL(d)` 흰 하이라이트 한 줄, `spk(x,y,r,색)` 반짝이
  - `at(조각, cx, cy, 배율, 회전)` 다른 조각을 옮겨 붙이기 (예: 모래시계 + 단검 = `t4-ambush-sand`)
- **글 속 이모지**: `#hud`·`#ext`·`#endCard`·`#down` 안에 이모지가 글로 들어오면 `watch()`가 그 글자 노드만 쪼개 그림으로 바꾼다(옆 요소 참조는 그대로). 토스트 `'🪽 깃털 발목이…'`, 하트 `♥`, 튜토리얼 조각 `⌛ 0/5`, 별 `★☆`, 되감기 `⟲` 등. `◆◇`는 T3 시험 방 표시라 일부러 뺐다.
- 매 프레임 글을 다시 쓰는 곳에는 이모지를 넣지 말 것(지켜보기가 매번 다시 그린다) — T3 씨앗·열쇠 HUD는 값이 바뀔 때만 쓰게 고쳤다.

## 5. 판넬 규칙 (시대에 따라 바뀜)

`body.past`(어제) = **금박**: 어두운 갈색 바탕 + 금 테 + 금 덩굴 귀퉁이, 제목 #ffe2a0, 마름모 띠. `body.now`(오늘) = **무너진 청록 돌**: 어두운 청록 바탕 + 빗금 돌결 + 금 간 돌덩이 귀퉁이, 제목 #c6f6ff, 깨진 돌 띠.

| 변수 | 어제 | 오늘 |
|---|---|---|
| `--pn-bg` | #211a10 → #0f0b07 | #11201f → #070f10 |
| `--pn-edge` / `-dk` / `-lt` | #e2b65e / #6e4a1a / #fff0c0 | #6cc4cc / #1f4248 / #d6fbff |
| `--pn-title` / `--pn-accent` | #ffe2a0 / #ffd27a | #c6f6ff / #7fe8ff |

- 틀 `.yk-frame`(T1 덮개 상자, 끝 화면, 시작·멈춤 카드), 제목 `.yk-h`(아래 장식 띠), 단추 `.yk-btn`(고르면 왼쪽에 단검 커서가 까딱).
- 카드(T4 고르기·쉼터·서고·가방): 희귀도 색 테 + 위쪽 빛, 가운데 **메달**(둥근 받침 위 아이콘, 저주는 점선 테), 희귀도 **보석**(흔함 1·드묾 2·전설 3개), 고르면 위로 7px + 빛, 아이콘이 살짝 떠오름.
- 지도: 지도판 위 **메달 칸**(종류 색 테), 지나온 칸은 빛바래고 체크, 지금 칸 위에 붉은 핀, 지나온 길 = 시대 강조색 실선, 갈 수 있는 길 = 밝은 점선.
- HUD: 하트(잃으면 점선 빈 홈), 모래 = 모래시계 + 유리관, 금화·탄 = 작은 명판, 유물 칸 = 희귀도 테 타일(축복은 둥글게, 시너지면 반짝이), 시대 이름 옆 문장(어제 해는 천천히 돎), 성채지기·문지기 체력 = 보석 점, 두 번 실패 tip = 등불.

## 8. 남은 것 / 다음에

- 지도 메달 아이콘은 34→38px로 키우고 먼 칸도 덜 흐리게 했다(11/15). 휴대폰(46px 칸)에선 아직 작은 편.
- 문지기 머리 위 보석 점은 3D 스프라이트라 장면 빛에 따라 색이 연해진다(켜짐/꺼짐 구별은 됨).
- 제목용 글꼴이 있으면 더 '게임' 같다 — 지금은 시스템 글꼴(맑은 고딕/Segoe UI). 새 글꼴은 내려받아야 해서 하지 않았다(개발자님이 정할 일).
- 아이콘 몇 개는 작게 보면 비슷하다: `t4-curse-blood`(계약서+피) ↔ `t4-curse-debt`(계약서+금화), `t4-reverse-glass` ↔ `t4-light-glass`(둘 다 모래시계). 색·덧그림으로 갈렸지만 16px에선 헷갈릴 수 있다.

## 합칠 때 메모

- `rl-t5`는 `rl-merge-r2fix`(d8de6f9) 위에서 시작. T1·T2·T3·T4 파일을 고친 곳은 모두 `t5-touch:` 커밋으로 따로 있다 — 그 사이 다른 트랙이 같은 파일을 고쳤다면 **CSS 묶음(`const CSS = \`…\``) 통째 교체**가 충돌 지점이다(`t1/ui.js`, `t4/ui.js`). 다른 트랙 쪽 변경을 살리고, T5 쪽에서 바뀐 것(색을 `--pn-*` 변수로, `.ico`를 메달로, `.gm` 보석, `#t4-bar .ic` 타일)을 다시 얹으면 된다.
- 공용 파일은 `src/ext/index.js`에 `import './t5-ui.js';` 한 줄(`core:`)뿐. index.html·main.js는 안 고쳤다(그쪽 HUD 모양은 `t5/theme.js`가 덮음 — 이 CSS가 맨 뒤에 붙어야 이긴다. `t5-ui.js`가 init에서 다시 붙임).
- 새 유물·적·장치에 아이콘이 없으면 원래 이모지가 그대로 나온다(깨지지 않음). 아이콘을 넣으려면 2장.
- `tools/build_itch.py`는 `src/**/*.js`를 다 담으므로 T5 파일도 들어간다(빌드 점검 결과는 일지).
