# 어제의 성채 로그라이크 — T5 UI 아트 안내 (11/15)

개발자님 말(11/15): "UI에 쓰이는 이미지가 지금 기본 이모지일 텐데, UI들 게임스럽게 개선하고 좀 어제의 성채 느낌 나는 그림들로 그려서 넣게끔."

공통 규칙은 `docs/roguelike/BRIEF-common.md`를 먼저 읽는다(직접 플레이 기준, 줄 끝, `$t`, 시험 서버, 기록·보고). 이 문서는 T5에만 해당하는 것과 공통 규칙에서 달라지는 점을 적는다.

## 1. 지금 상태

- 바탕 커밋: `rl-merge-r2fix` 끝(`d8de6f9`) = main `f0d0918` + T1~T4 2차 고칠 것 + `core:` 토스트 줄바꿈. 아직 main에 올리기 전인 "시험 합치기" 판이다. 개발자님이 합치라고 하면 main이 이 커밋으로 그대로 앞당겨지므로, T5 브랜치 `rl-t5`는 나중에 충돌 없이 합쳐진다.
- T1~T4는 2차 고칠 것까지 마쳤고, 지금 맡은 일이 없다. 그래서 이번에는 **T5가 화면 코드를 맡는다**(아래 2장).
- 화면 그림은 지금 OS 이모지·유니코드 기호다. 이모지 쓰는 곳이 많은 파일: `src/ext/t4/items.js`(유물 아이콘 56곳), `src/ext/t4/ui.js`(HUD·고르기 창·상점), `src/ext/t1/map.js`(지도 칸 ⚔ ✦ ◆ ☾ ♜), `src/ext/t1/ui.js`(런 메뉴·요약), `src/ext/t1-run.js`, `src/main.js`(HUD·튜토리얼 문구), `index.html`(`#hint.tip::before`의 💡 등 CSS), `src/ext/t2/chunks*.js`·`t3/*`(안내 문구 속 기호).
- 이모지는 Windows·Mac·리눅스에서 모양이 다 다르게 그려진다. 잼 심사자 화면에서 모양이 달라지는 문제도 이번에 같이 없어진다.

## 2. 맡는 범위와 고쳐도 되는 파일

**할 일**
1. **한 벌의 그린 아이콘**으로 이모지·기호를 바꾼다.
   - 유물·축복·저주 아이콘 전부(T4 `items.js`의 `icon`, 저주 포함), 해금 아이콘.
   - HUD: 금화 🪙, 모래 ⌛, 하트 ♥, 칼 🔪·화살 ➶ 탄 수, 문지기·성채지기 체력 표시(보스 점).
   - 지도 칸: 전투 ⚔, 퍼즐 ✦, 보물 ◆, 상점, 쉼터 ☾, 문지기 ♜, 지나온 칸·지금 칸 표시.
   - 안내·tip 앞 기호(💡), 토스트 속 금화·모래 같은 자주 나오는 기호.
2. **화면을 게임답게** 다시 꾸민다: 시작·런 메뉴, 층 지도, 셋 중 하나 고르기 창, Tab 유물 목록, 상점, 쉼터, 런 요약, 끝 화면, 상단 HUD(하트·모래·금화·유물 줄). 판넬 테두리·제목 띠·단추·희귀도 테두리를 한 가지 말투로.
3. 그림 느낌: **어제 = 금박의 따뜻한 금빛**(경비가 살던 황금기), **오늘 = 무너진 청록빛 돌**(폐허, 골렘). 지금 던전 Fab 모델·조명과 어울리게. 희귀도(보통·드묾·전설)와 저주가 한눈에 구별되게.

**어떻게 그리나**
- 기본은 **코드 안에서 직접 그린 SVG**(또는 canvas). 아무것도 내려받지 않는다. 이미지 생성 같은 외부 서비스나 새 글꼴을 내려받아야 할 것 같으면 하지 말고 보고에 "이게 있으면 낫겠다"로 적는다(개발자님이 정한다).
- 아이콘은 한 곳에 모은다: 새 파일 `src/ext/t5/icons.js`(예: `EXT.icon(id, opts) → SVG 문자열`, `EXT.icons[id]`). 다른 파일은 이모지 대신 이걸 부른다. 등록 안 된 id가 오면 원래 글자를 그대로 보여 주는 안전한 길을 둔다(나중에 다른 트랙이 새 유물을 넣어도 깨지지 않게).
- 같은 격자(예: 24×24 viewBox), 같은 선 굵기·테두리 색·그림자로 한 벌처럼. HUD는 작게(16~20px)도 읽혀야 한다.
- 무게: 첫 로딩은 지금 약 5.3MB(빌드 약 5.0MB), 목표 6.0MB 아래 유지. SVG를 JS 문자열로 두면 거의 늘지 않는다. HUD에 매 프레임 innerHTML을 다시 쓰지 않게(바뀔 때만).

**고쳐도 되는 파일(이번 T5만 예외)**
- 자기 것: `src/ext/t5/*`(새로), `src/ext/t5-ui.js` 같은 슬롯이 필요하면 `src/ext/index.js`에 import 한 줄(`core:` 커밋으로), `docs/roguelike/t5.md`, `devlog/tracks/t5.md`, `devlog/shots/2026-11-xx-t5/`, `tools/t5_*`.
- 화면 때문에 다른 트랙 파일도 고쳐도 된다: `src/ext/t1/ui.js`, `src/ext/t1/map.js`, `src/ext/t4/ui.js`, `src/ext/t4/items.js`(`icon` 칸만), 그 밖에 이모지가 화면에 나가는 자리. **규칙**: 그림·꾸밈·표시만 바꾸고 게임 규칙·수치·문구 뜻은 건드리지 않는다. 커밋을 파일 묶음별로 나누고 메시지를 `t5-touch: <파일> …`로 시작한다.
- 공용 파일(`index.html` CSS·HUD 마크업, `src/main.js` HUD)은 가장 작게, 따로 `core: …` 커밋. `src/main.js`는 CRLF(바이트로 읽고 쓰기, Edit 도구는 괜찮음).
- 문구를 바꾸면 영어도: 자기 `src/ext/t5/en.js` 또는 그 문구가 있던 트랙의 `en.js`.

## 3. 확인할 것

- **직접 플레이가 기준**: 바꾼 화면마다 진짜 키 입력으로 열어 본다. 마지막에 처음 보는 사람처럼 타이틀 → 튜토리얼 첫 방 → 런 시작 → 지도 → 방 몇 개 → 고르기 창 → 상점·쉼터 → 죽음 → 런 요약 → 다시 시작 → 이어하기까지 통째로.
- 화면 크기 둘: 데스크톱 1280×720, 휴대폰 세로 390×844. 글자 넘침·겹침·잘림이 없게. 언어 둘: 한국어·영어(`?lang=en` 또는 게임 설정).
- 어제·오늘 두 시대에서 HUD가 둘 다 잘 읽히는지(밝은 금빛 바닥 위, 어두운 청록 바닥 위).
- 전후 비교 스크린샷(같은 장면 바꾸기 전/후)을 남긴다 — 개발자님 보고와 영상에 쓴다.
- 회귀: `py -I tools\release_check.py` 13/13 그대로, 콘솔 오류 0, 번역 빠짐 0. `py -I tools\build_itch.py` 후 `py -I tools\release_check.py build\itch\web`도(빌드 축소가 새 파일을 빠뜨린 적이 있다 — T4 2차 참고).
- 직접 플레이 서버 포트 **8155**: `py -I tools\play_server.py 8155 <스크래치 폴더>`. 앱의 미리보기 창(Browser pane)은 쓰지 않는다.
