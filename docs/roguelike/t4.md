# T4 아이템·성장 — 설계와 규칙 (11/13)

브랜치 `rl-t4`. 코드: `src/ext/t4-items.js`(슬롯) + `src/ext/t4/` (`items.js` 표 · `core.js` 능력치·훅·던지기 · `ui.js` 화면 · `rooms.js` 방·시험 런 · `meta.js` 런 사이 해금 · `sfx.js` 소리 · `en.js` 영어). 도구: `tools/t4_lang.py`(영어 빠짐 검사), `tools/t4_balance.py`(게으른 봇 균형 시험).

## 0. 지키는 약속

- **유물이 하나도 없으면 아무것도 안 바꾼다.** 능력치는 `put()`이 "기본값 × 배수 + 더하기"로 쓰는데, 배수 1·더하기 0이면 원래 값으로 되돌리고 손을 뗀다(다른 트랙이 바꾼 값을 덮지 않게). 훅도 `live()`(유물 있음)일 때만 일한다. 튜토리얼 13방 출시 점검 13/13 그대로.
- T4가 고치는 값: `EXT.stats`(maxHearts·shiftCd·rollCd·lunge·speed, 새 `sandMul`), `K.GUARD`(range·half·susNear·susFar·shock), `K.GOLEM`(sense·susNear·susFar), 방 데이터 `gateHold`(창살 쐐기, 방을 떠나면 되돌림). 처음 고칠 때의 값을 `EXT.t4.T4.base['STAT.speed']`처럼 기억한다 → **T1이 기본값을 바꾸고 싶으면** 그 키가 있으면 거기를 바꾸고 `EXT.t4.apply()`, 없으면 그냥 바꾸면 된다.
- 런 상태·모래·하트는 T1 것. T4는 `EXT.run?.addSand?.()`처럼 있을 때만 부른다. T1이 없으면 모래 유물 2개(`needs: 'sand'`)는 아예 안 나온다.

## 2. 화면

- **고르기 창**(셋 중 하나): `#ext` 안 `#t4-ov`. 열려 있는 동안 `K.freeze(true)` + 매 프레임 다시 멈춤(일시정지 카드를 닫아도 계속 멈춤). 키는 캡처 단계에서 먼저 받아 게임으로 안 넘김(Shift를 눌러도 시대가 안 바뀜) — 일시정지 카드가 떠 있으면 그쪽에 양보. ←→/AD/1~9 고르기, Enter·Space·E 가져가기(**J는 안 됨** — 찌르다 잘못 가져가던 문제), Esc 건너뛰기(금화 +4), R 다시 뽑기(해금 시). 창을 연 키가 0.3초 안에 그대로 고르지 않게 막음. 마우스: 올리면 고름, 누르면 가져감.
- **HUD**: 오른쪽 시대 표시 아래 세로 줄 — 금화, 던질 것(🔪 n/m · ➶ n, Q), 유물 아이콘(희귀도 색 틀, 축복은 둥근 틀, II 표시, 시너지 ✦, 다 쓴 방패·태엽·심장·잔상 쿨다운은 흐리게). 아이콘에 마우스를 올리면(휴대폰은 누르면) 설명 풍선. **Tab / I** = 가진 유물·시너지 목록(세상 멈춤). 유물·금화가 없고 런도 아니면 줄 자체가 안 보임. 끝 화면·멈춤 카드 뒤로는 숨김.
- 휴대폰(390×844)·가로(844×390): 카드가 세로로 쌓이고 아이콘 2열. 한국어는 낱말 단위 줄바꿈(`keep-all`).

## 3. 방 종류와 재화

| 방 | id (시험) | 하는 일 |
|---|---|---|
| 보물 방 | `t4-treasure` | 제단(E, 2m 안) → 고르기 창. 한 번만 |
| 떠돌이 상점 | `t4-shop` | 받침대 3개(유물만, 축복 없음) + 하트 +1 받침대. 곁에 서면 설명 카드 + "E 사기 — 금화 n" |
| 모닥불 쉼터 | `t4-rest` | 하나만: 하트 2개 회복 **또는** 유물 하나 II로 강화 |

| 시험장 | `t4-arena` | 어제 경비 둘(순찰·보초) + 화살 줄 + 가시, 오늘 골렘(보초 자리를 지나감 → 겹친 순간), 두 시대 구덩이 |

**재화 = 금화(새로 만듦)**. 모래시계 조각은 T1에서 모래(어제 시간)를 채우는 데 쓰이므로 겹치지 않게 따로 뒀다. 처치 +1(보스 +8), **경보 없이 적을 다 잡고 나가면 +2**(잠입 보상), 보물 건너뛰기 +4.
가격: 흔함 6 · 드묾 10 · 전설 16 · 하트 4 (도둑의 주머니 할인). 직접 플레이 시험 런에서 방 3개(적 5) 뒤 9개 → 흔한 것 하나, 초소까지 지나 12개 → 흔한 것 둘 정도. T1 층이 방 6~8개면 상점마다 1~2개 살 수 있는 정도를 노렸다.

얻는 기억 = 지난 방 수 + 층 × 3 + 이기면 10 + 남은 금화 ÷ 4 (최소 1). 시험 런 한 판(이김) = 13. 다 열려면 5~7판. **힘을 계속 올리는 해금(최대 하트 영구 +1 같은 것)은 넣지 않았다** — 종류만 늘고 시작이 조금 편해질 뿐.

## 5. T1이 쓰는 것 — `EXT.t4`

```js
EXT.t4.startRun()                  // 런 시작: 유물·금화 초기화 + 해금 적용(여윳돈·다시 뽑기·시작 유물 고르기 → Promise)
EXT.t4.endRun({ won, floors, rooms }) // 런 끝: 기억 쌓기(돌려줌). 그 뒤 EXT.t4.openMeta({ gain, cont: '새 런' })로 서고 창
EXT.t4.roomFor('treasure'|'shop'|'rest', { tier, label, startEra }) // 방 데이터(새 객체)
EXT.t4.decorate(room, 'shop', { at: [[i,j]…], tier })              // T1이 만든 방에 제단 붙이기(없으면 방 가운데)
EXT.t4.openPick({ count: 3, tier, title, kinds: ['relic','blessing'] }) // 정예·층 보상 → Promise<id|null>
EXT.t4.openRest({ heal: 2 }), EXT.t4.openInv()
EXT.t4.snapshot() / EXT.t4.restore(s) // 이어하기 저장
EXT.t4.addCoins(n), EXT.t4.coins, EXT.t4.inv, EXT.t4.has(id), EXT.t4.lv(id), EXT.t4.give(id, { lv })
EXT.t4.panelOpen()                 // 창이 떠 있는지 (T1 지도 창과 겹치지 않게)
```
- `EXT.run.registerRoomType(type, { track, make(opts), decorate(room, opts) })`가 init 때 있으면 보물·상점·쉼터를 거기 등록한다.
- **T4가 T1에게 바라는 것**: `EXT.run.addSand(초)`(피의 모래), `EXT.run.floor`(상점·보물 희귀도), 모래 최대치에 `EXT.stats.sandMul ?? 1`을 곱하기. 하트를 다시 채울 때 `EXT.stats.maxHearts`를 쓰기(유물이 바꿈).
- `EXT.run`이 있으면 T4의 시험 런(nextRoom·death·end 훅)은 아무것도 안 한다.
- 금화 보너스(+2)는 `T4.run.active`일 때만 → T1은 `startRun()`을 불러야 한다.

## 6. 다른 트랙에게 (T2)

- 확장 적이 던진 단검에 맞으면: `f.onThrown({ behind, dx, dz, kind })`가 있으면 그걸 부르고('pierce'를 돌려주면 계속 날아감), 없으면 등이면 `K.killed(f, 'back')`, 앞이면 `f.stun` 0.4초.
- 등 판정·잔상·유리 단검은 `f.yaw`를 쓴다. 유리 단검은 확장 적엔 안 통함, 암살자의 눈은 확장 적이면 `onStab({…info, behind: true})`로 넘긴다.
- 시간 파문·방패 II·겹친 순간은 `f.stun`·`K.killFoe`를 쓴다.

## 7. 공용 파일 변경 (`core:` 커밋 e3f9ca0)

## 12. 출시: 첫 로딩 6.35 → 4.84MB, itch 빌드에서 런이 돈다

- **빌드에 `src/ext/`가 빠져 있었다**(`('src', ['*.js'])`가 맨 위만 복사) → 빌드는 게임이 안 뜨는 상태였다. 이제 `src/**`(src/dev 빼고).
- `tools/t4_minify.py`: 새 프로그램 없이 파이썬으로 JS의 주석·들여쓰기·쓸데없는 빈칸만 지움(문자열·템플릿·정규식·줄바꿈은 그대로). 0.85 → 0.61MB. `--check`로 다시 줄여도 같은지(멱등) 확인.
- `core:` ec719d3: 경비 모델(약 1.2MB)을 첫 방 뒤 백그라운드로(골렘과 같은 방식). 첫 방(튜토리얼 다리·런 계단참)엔 경비가 없다. 그 전에 경비 방에 들어오면 모델이 오는 대로 세우고, 그때까지 출구는 닫힘(`S.guardPending`). T2 사람 적은 모델이 없으면 원래 캡슐로 대신 나옴.
- 결과(빌드 폴더 점검): **첫 로딩 4.84MB / 148개**(목표 6.0), 전체 8.15MB, 튜토리얼 13/13, 콘솔 오류 0, 번역 빠짐 0. 빌드를 `t4_play_build.py`로 띄워 시작 메뉴 → 새 런 → 계단참 → 1층 지도까지 진짜 키로 확인.
